# Meowgent 조사 정리 (2026-10-17)

Meowgent = 내 컴퓨터 작업을 지켜보며 기록하고, 피드백을 받고, 메모·할 일·일정을 챙겨 주는 데스크톱 고양이 비서.
아래는 시작 전에 조사한 내용과 그에 따른 결정이다. (원문 출처 링크 포함)

---

## 1. 고양이를 화면에 띄우는 방법 (비슷한 프로그램 코드 조사)

**결정: 웹뷰가 아니라 맥 기본 그리기(네이티브)로 만든다.**
- 봉고캣(BongoCat, 깃허브 별 2.4만)이 처음엔 웹뷰(Tauri + PixiJS + Live2D)로 만들었다가 메모리 500MB 이상, CPU 튀는 문제, macOS 26에서 흰 테두리 버그 때문에 2026-09에 네이티브(Rust + Metal)로 갈아엎었다. https://github.com/ayangweb/BongoCat
- 가장 가까운 Swift 예제 jke48222/WindowPet(MIT): 잘 때 CPU 0.25%, 걸을 때 1.04%, 메모리 44MB. https://github.com/jke48222/WindowPet

**가져다 쓸 수 있는 코드 (자유 라이선스)**

| 출처 | 라이선스 | 가져올 것 |
|---|---|---|
| jke48222/WindowPet | MIT | 투명·포커스 안 뺏는 창, 다른 창 위치 읽기(권한 불필요), 창 윗변 위를 걷는 지형 계산, 중력·점프 계산, 고양이 그림 부분만 클릭되게 하기, 잡아서 던지기, 움직일 때만 화면 갱신(배터리 절약) |
| iappyx/DesktopPetMac | MIT | Dock 윗변을 바닥으로 쓰기, 좌표계 변환 |
| mmar/Cat | 0BSD | 핥기→긁기→하품→잠 같은 한가할 때 행동 순서 |
| ayangweb/BongoCat | Apache-2.0 | 키 입력 감지 방식, 메뉴바 위에 뜨는 창 높이(레벨 25) 이유 (Rust라 아이디어만) |
| Shimeji 계열 | BSD 계열 | "조건 + 확률"로 행동 고르는 설계 아이디어 |
| ❌ Shijima-Qt (GPL), 라이선스 없는 저장소, Live2D 코어, 원조 Neko 그림 | | 쓰지 않음 |

**핵심 기술 메모**
- 다른 앱 창 위치·순서는 권한 없이 읽을 수 있다 (`CGWindowListCopyWindowInfo`). 창 제목·앱 이름은 화면 기록 권한이 필요 → 앱 이름은 프로세스 번호로 따로 찾는다.
- 화면 전체를 덮는 투명 창을 깔고 고양이는 그 안의 그림 레이어로 움직인다(창을 움직이는 것보다 훨씬 가볍다).
- 기본은 "클릭 통과", 마우스가 고양이 그림 위에 있을 때만 클릭을 받는다.
- 고양이가 창을 "건드리는" 건 **보이기만** 한다. 실제로 다른 창을 움직이거나 클릭하지 않는다.

**화면 공유·발표 중 숨기기**
- 맥에는 "지금 화면이 공유되는 중"을 알려 주는 공식 방법이 없다. `sharingType = .none`도 macOS 15/26에서 확실히 숨겨지지 않는다(QuickTime 녹화에 잡힘). → 설정은 하되 믿지 않는다.
- 실제로 쓸 방법: ① 전체 화면(키노트 발표, 전체 화면 줌·영상)에서는 아예 안 나타나게 ② 앞 창이 화면의 98.5% 이상을 덮으면 숨기기 ③ 회의 앱이 회의 중이면 작게/숨기기 ④ 메뉴바 토글 + 단축키.

## 2. 고양이 그림

**결정: 도트(픽셀) 그림. Last tick "Cat Animation Pack" 사용.**
- 64×64, 3색(검정·주황·흰색), 동작 56개: 4방향 걷기·뛰기, 앞발 핥기, 야옹, 긁기, 꼬리 흔들기, **앉아서 왼발·오른발 휘두르기(→ 봉고캣식 타자)**, 하품, 잠 5종, 밥 먹기, 하악질, 점프, 두 발로 서기, 눕기·기지개.
- 라이선스: 개인·상업 사용 가능, 수정 가능, 재배포·AI 학습 금지 → 그림 파일은 git에 올리지 않는다(`assets/vendor/`).
- 비교한 다른 선택지: Rive(벡터, 상호작용 최고지만 고양이 캐릭터를 직접 만들어야 함), Lottie(작가마다 그림체가 달라 섞으면 어색함), Live2D(정면만 가능, 걷기 불가), 3D·실사 영상(무겁고 상호작용 어려움).
- 동글동글한 ToffeeCraft 팩은 무료판이 3동작뿐이라 보류. 유료판($1.80)은 원하면 직접 구입 후 추가.

## 3. AI 비서 고양이 — 언제 말을 걸까

**비슷한 제품**: Dinoki(맥, 도트 펫 + AI), Clippy 부활판, Desktop Mate, MateEngine, Screenpipe 등.
- 사람들이 싫어한 것: 귀엽기만 하고 쓸모없음, 화면을 어디로 보내는지 모름, 유료 결제 위주.
- "활동 감지 + 규칙 학습 + 매일 승인" 조합은 아직 없는 것 같다 → Meowgent의 차별점.

**연구에서 나온 규칙**
- 일하는 중간이 아니라 **일의 경계**에서만 말을 건다: 앱·프로젝트 전환, 입력이 멈춘 지 5초 뒤, 자리에서 돌아왔을 때. (Microsoft Research, Iqbal & Bailey)
- CHI 2025 연구: 타자 칠 땐 절대 안 보여 주고, 5초 쉬면 보여 주고, 20초에 한 번 이하 → 90%가 좋아함. 계속 말 거는 버전은 47%만 좋아함("귀찮다").
- 그래서:
  1. 표현은 대부분 **몸짓**(앉기·자기·기지개)으로, 말풍선은 드물게.
  2. 말풍선은 20분에 1번, 하루 6~8번 이하. 회의·화면 공유·집중 모드 중엔 안 함.
  3. 👎나 무시가 3번 쌓이면 그 종류 알림은 다음 날 아침까지 끔.
  4. 모든 말풍선에 "왜?"(근거) 보기, 한 번에 닫기.
  5. 배고픔·죽음 같은 **죄책감 장치 없음**. 무시해도 슬퍼하지 않음.

## 4. 밤에 배우는 구조 (자는 동안 정리)

- AI가 규칙을 직접 고치지 않고 **"추가/수정/추천/비추천/폐기" 제안만** 한다 (ExpeL 방식).
- 제안마다 근거 기록 번호를 붙이고, 최근 1~2주 기록에 다시 돌려 정확도를 확인한 뒤에만 아침 브리핑에 올린다.
- 아침에 하나씩 승인 → 승인된 규칙도 1~2일은 "조용히 시험"만 하다가 맞으면 정식 적용.
- 내가 직접 만든 규칙은 AI가 못 건드림. 하루 변경 5개 이하. 규칙은 git으로 버전 관리 → "어제로 되돌리기" 한 번에.
- 맥북이라 밤에 꺼져 있으므로 **아침에 처음 열 때 어제 것 정리 → 브리핑**.

## 5. 메모·할 일·일정

- 맥 기본 날짜 인식기(NSDataDetector)가 한국어를 꽤 읽는다: "내일 오후 3시", "다음주 화요일", "모레 10시" ✓ / "3일 후" ✗, "이번 주 금요일"은 지난 날짜로 읽음 → 정규식 10개 정도로 보완.
- 일정·미리 알림 연동(EventKit): 일정을 읽으려면 "전체 접근" 권한 필요.
- 빠른 입력: 단축키 → 고양이 옆 한 줄 입력창 → 날짜를 칩으로 보여 주고 고칠 수 있게.

## 6. 추가 기능 아이디어 (사용자 제안 + 추천)

1. **컴퓨터 느려질 때**: 어느 앱이 CPU·메모리를 많이 쓰는지 간단히 (크롬 탭들은 합쳐서). 강제 종료는 절대 자동으로 안 함.
2. **에이전트 컨텍스트·토큰 감시**
   - Codex: 로컬 기록에 컨텍스트 한도(258k), 사용량, **주간 한도 사용률·초기화 시각**까지 있음 ✓
   - Claude Code: 턴마다 사용 토큰 → 컨텍스트 % 계산 가능 ✓. 요금제 한도는 로컬에 없음 → CodexBar 앱 방식 참고.
   - Cursor·Grok Bot: 로컬 기록 미확인.
   - 50%·80% 경고, 한도 80%·90% 경고, 오늘 쓴 토큰.
3. 추천: 에이전트가 일 끝내고 나를 기다릴 때 알려 주기 ⭐, API 키를 웹·채팅에 붙여넣으면 즉시 경고 ⭐, "어디까지 했더라?", 반복 작업 발견 → 자동화 제안, 90분 집중 후 휴식 권유, 하루 업무 요약 초안, 주간 패턴 리포트.
4. 아이디어 계속 찾기: 주 1회 자동 조사(데스크톱 펫·Raycast·screenpipe 등), "아이디어:" 메모함, 내 기록에서 반복 패턴 찾기.
