# Meowgent 앱 (수집기 + 고양이)

메뉴바에 떠 있으면서 고양이를 띄우고, 켜 두면 맥에서 하는 행동을 기록하는 앱. 번들 ID `io.github.jasonwpgml.meowgent`. 전체 설계는 [../DESIGN.md](../DESIGN.md).

## 활동 기록은 옵트인

처음 실행하면 "고양이만 / 활동 기록도 켜기"를 묻는다. 기본은 고양이만이고, 이때는 아래 표의 어떤 것도 저장하지 않는다 (고양이·단축키 힌트·사용량 리마인드는 동작).
메뉴바 › "활동 기록 켜기" / "활동 기록 끄기 (고양이만)"으로 바꾸며, 설정은 `recordingEnabled`(UserDefaults)에 남는다. 이미 기록이 있던 설치는 켠 상태를 유지한다.

## 무엇을 기록하나 (켰을 때)

| 종류 (`source`) | 내용 | 언제 |
|---|---|---|
| `app` | 앞에 나온 앱 | 앱 전환 |
| `window` | 창 제목, 문서 경로 | 창·제목 변경 |
| `browser` | 페이지 주소, 제목 (Chrome·Arc·Brave·Edge·Whale·Safari) | 탭·주소 변경, 5초마다 확인 |
| `search` | 검색어 (구글·네이버·다음·유튜브·깃허브 등) | 검색 결과 페이지 진입 |
| `text` | 입력한 글 (한글은 조합 완료된 상태로). AI에게 보낸 질문은 `kind: ai_prompt`, 붙여넣은 글이 섞이면 `pasted_chars` | Enter, 입력창 이동, 8초 멈춤 (AI 대화창은 Enter·이동 때만) |
| `ai_response` | AI 답변 (웹의 Gemini·구글 AI 모드·ChatGPT·Claude 등). 데스크톱 앱 답변은 기본 제외(AI hub가 수집) | 질문 후 답변이 다 나왔을 때 |
| `click` | 누른 버튼·링크·메뉴 이름 | 클릭 |
| `activity` | 1분간 키·클릭·스크롤 횟수, 마우스 이동 거리 | 1분마다 |
| `afk` | 자리 비움(3분 무입력), 화면 잠금, 잠자기 | 상태 변화 |
| `clipboard` | 복사한 글 (앞 5000자) | 복사 |
| `paste` | 붙여넣은 내용 + 붙여넣은 곳(앱·창·주소·입력창) | Cmd+V |
| `secure` | 다른 앱이 보안 입력을 켜서 키 횟수를 못 세는 구간 | 상태 변화 |
| `health` | 권한·탭 상태, DB 크기 | 1분마다 |

단축키 힌트용 기록은 DB가 아니라 `shortcuts.json`에 따로 둔다: 마우스로 한 동작(예: Chrome 뒤로 단추)별로 날짜별 마우스 횟수, 그 동작의 단축키를 키보드로 쓴 횟수, 힌트를 보여 준 날. 자세한 내용은 [../docs/SHORTCUT_HINTS.md](../docs/SHORTCUT_HINTS.md).

## 기록하지 않는 것
- 비밀번호 칸 (내용은 절대 읽지 않음)
- 비밀번호 관리자·키체인 앱이 앞에 있을 때의 내용
- 은행·증권·카드·결제·정부 사이트에서의 주소·입력·클릭 내용 (시간만 남음)
- 시크릿 창 (Chromium 계열: Chrome·Arc·Brave·Edge·Whale 등). **Safari는 개인 정보 보호 창을 구분할 방법이 없어 기본으로 Safari 페이지의 주소·내용을 기록하지 않는다.** config.json에 `"trustSafari": true`를 넣으면 기록하되 개인 정보 보호 창도 같이 기록된다
- 브라우저 주소를 못 읽는 동안 (자동화 권한을 거부했거나, 탭을 바꾼 직후 응답 전, 조회 실패): 그 사이 입력·복사·붙여넣기 내용은 저장하지 않는다 (모르면 막힌 것으로 본다)
- 비밀번호 칸에 포커스가 있거나 다른 앱이 보안 입력을 켠 동안의 복사·붙여넣기 내용
- 터미널 입력 (화면 전체가 섞이고 셸 기록이 따로 있음)
- API 키·토큰·카드번호·주민번호·"비밀번호: …" 형태는 저장 전에 `[REDACTED]`로 가림
- 키보드로 무슨 글자를 눌렀는지 (횟수와 Enter 여부만 본다). ⌘·⌃와 함께 누른 조합만 메모리에서 확인하고, 마우스로 해 본 동작의 단축키일 때만 그 동작의 횟수를 늘린다. 그 밖의 조합은 남기지 않는다

차단 목록은 `~/Library/Application Support/ActLog/config.json`에서 고칠 수 있음 (메뉴 → 설정 파일 열기). 고친 뒤 메뉴 → 다시 시작.

## 설치·업데이트
```bash
./build.sh
```
`~/Applications/Meowgent.app`에 설치하고 실행한다. 고양이 코드·원화는 비공개 `../pet/` 서브모듈에서 오고(`setup-pet.sh`가 링크), 원화는 AES로 잠긴 `.sprite`로 번들에 들어간다. 개발 빌드에는 팩 그림(assets/vendor)도 들어간다.

배포본(팩 그림 제외, 심볼 제거)은 `./release.sh` → `dist/`. Developer ID가 있으면 `SIGN_ID`·`NOTARY_PROFILE`을 주면 DMG 공증까지 한다. 자세한 절차는 [../docs/RELEASE.md](../docs/RELEASE.md).

처음 실행하면 macOS가 두 가지 권한을 묻는다: **손쉬운 사용**, **입력 모니터링**.
시스템 설정에서 Meowgent를 켠 뒤 메뉴바 아이콘 → **Meowgent 다시 시작**.
브라우저를 처음 쓸 때는 "Meowgent가 Chrome을 제어하려고 합니다" 창이 뜬다 → 허용 (주소를 읽기 위해).

> 키체인의 "ActLog Local Signing" 인증서로 서명하므로 다시 빌드해도 권한이 유지된다.
> 인증서가 없는 맥에서는 임시 서명이 되어 **빌드마다 권한을 다시 켜야 한다** (설정에서 −로 지우고 +로 다시 추가).

메뉴바 아이콘: `◉` 기록 중 · `◎` 권한 필요 · `◌` 일시정지

## 런처
`⌘⇧Space`로 여는 검색창 (Raycast 비슷한 것). 메뉴 막대 → 🔎 런처에서 `⌘Space`로 바꿀 수 있다 (Spotlight·Raycast의 ⌘Space를 먼저 꺼야 잡힌다).
- **앱 열기**: 한국어 이름·영문 이름·초성(`ㅋㄹ` → 캘린더)·한글 자판 상태로 친 영문(`초개ㅡㄷ` → Chrome) 모두 찾는다. 자주 연 앱이 위로 온다.
- **계산기**: `12*(3+4)/2`, `1,000 × 3` → ⏎ 로 결과 복사.
- **창 배치**: `왼쪽`·`오른쪽`·`위쪽`·`아래쪽`·`최대화`·`가운데` → 런처를 열기 전 앞에 있던 창을 옮긴다 (손쉬운 사용 권한).
- **주소·웹 검색**: `example.com`은 바로 열고, 그 밖의 글은 맨 아래 줄에서 구글 검색.
- **클립보드 기록** (따로 켜는 기능, 기본 꺼짐): `⌃⌘V` 또는 런처에서 Tab. 오른쪽에 미리보기(글 전체·이미지·색 견본·파일 경로)가 붙는다.
  - 담는 것: 글(서식 RTF·HTML 포함), 링크, 색(`#3a7bd5`·`rgb(…)`), 이미지, 파일. 이미지는 글자를 읽어(한국어·영어, macOS 문자 인식) 그 글자로도 찾는다.
  - 키: ⏎ 붙여넣기 · ⇧⏎ 서식 없이 · ⌘⏎ 복사만 · ⌘1–9 그 줄 바로 붙여넣기 · ⌘P 고정 · ⌘⌫ 지우기 · ⌘[ ⌘] 종류 거르기(전체·글·링크·이미지·파일·색)
  - 보관: 고정한 것은 계속, 나머지는 보관 기간(기본 30일, 메뉴에서 7일~제한 없음)과 최근 500개 안에서. 메뉴 막대 → 🔎 런처 → 기록 안 할 앱에서 앱별로 끌 수 있다.
  - 저장: `clipboard/`(폴더 0700, 파일 0600)에 AES-GCM으로 암호화해서 두고, 열쇠는 키체인에만 있다(이 맥 전용). 끄면 고정한 것까지 바로 지운다.
  - 남기지 않는 것: 비밀번호 관리자에서 복사한 것, 보안 입력 중, 막은 앱·사이트·시크릿 창에서 복사한 것, 주소를 아직 못 읽은 브라우저(Safari는 `trustSafari`를 켜기 전까지 늘)에서 복사한 것, 키·토큰·카드번호처럼 보이는 글. 이미지는 읽은 글자에 같은 규칙을 적용하고, 글자 인식 자체가 실패한 이미지는 확인할 수 없으니 남기지 않는다.

자주 연 앱 순위(`launcher.json`, 앱 경로별 연 횟수·마지막 시각)는 활동 기록이 켜져 있을 때만 디스크에 남기고, 기록을 끄면 지운다.

## 대시보드
메뉴바 · 고양이 우클릭 → 📋 대시보드, 또는 런처에서 `대시보드`. 맥 기본 앱처럼 왼쪽 사이드바 · 위 도구 막대(제목·개수·찾기) · 회색 묶음 칸으로 되어 있다. 탭은 사이드바나 ⌘1–⌘6 (질문 · 경고 · 알림 · 생각 · 작업 · 개선). 고양이에게 "작업 탭 열어"처럼 말해도 연다.
키: 숫자 1–9 = 맨 위 묶음(조금 진한 칸, 버튼 앞 흐린 번호)에 그 선택지로 답 · ⌘Z = 방금 한 답 되돌리기 · ⌘F = 찾기. 잘린 설명·알림은 눌러서 펼친다.
- **질문**: 고양이 ! · ? 항목([docs/INBOX.md](../docs/INBOX.md)). 같은 곳에서 같은 선택지로 물은 질문은 한 카드로 묶이고, 함께 끝나는 문구("…Claude에서 한 일은 어느 프로젝트?")는 제목으로 한 번만 보인다. 선택지 버튼 하나로 체크한 질문 전부에 답하고, 다른 답이 필요한 것은 그 줄의 "따로"에서 고른다. 여러 개 골라도 되는 질문(`multi`, 고양이 되묻기·투표)은 체크 상자로 고르고 "n개 고르기"로 답한다. 직접 적기·건너뛰기·확인도 여기서. 답하면 창 아래 막대에서 되돌린다.
- **경고**: 고양이가 급하게 알린 것(컨텍스트·한도 등, 대화 답은 뺌) 최근 7일. 처음 대시보드를 연 뒤 새로 온 경고만 개수로 센다.
- **알림**: 나머지 고양이 알림. 숫자만 바뀌며 연달아 온 알림(컨텍스트 80% → 85%, 메모리 경고)은 한 줄로 접고, 종류별 단색 아이콘(컨텍스트·한도·메모리·완료·쉬기…)을 붙인다. 안 읽은 경고는 굵은 글씨와 강조색 점.

- **생각**: 말하는 고양이(cat_mind)가 먼저 말을 걸지 판단한 기록(`mind/decisions.jsonl`). 신호(돌아옴·막힘…) · 방식 · 결과(말함·참음·실패·시간 초과) · 말할 확률 · 걸린 시간 · 한 말. 최근 7일 말함/참음/실패 수를 위에 보인다. 말한 것엔 사용자 반응(답함·읽기만 함·무시·👎·🔇)을 붙이고, 먼저 말 건 판단마다 "말한 게 맞다 / 괜히 말했다" 같은 라벨 버튼이 있다([docs/CAT_MIND.md](../docs/CAT_MIND.md#말풍선-반응-기록-2026-11-07-실시간-업무-보조-0단계)).
- **작업**: 고양이에게 시켜 Claude Code·Codex·Cursor·Grok이 worktree에서 하는 코딩 작업([docs/CAT_MIND.md](../docs/CAT_MIND.md#시키면-하기--되묻기-2026-11-04-구현)). 하는 중·끝난 것, 요약, 브랜치, 폴더 열기·기록 보기·멈추기. 합칠지는 질문 탭에서 고른다.
- **개선**: 매주 개선 제안(기본 꺼짐, 켤 때 무엇을 보내는지 묻는다). 지난 7일 알림 통계(대화·작업 이름과 숫자는 가림)와 판단 통계, 지금 문구·설정을 고양이 전용 Codex 계정으로 보내 제안을 받는다. 입력한 글·활동 기록·고양이와 나눈 대화는 보내지 않는다. 문구·설정 제안은 [적용]하면 `phrases.json`만 바뀌고(다시 빌드 안 함), 아이디어는 [확인]만. "지금 받기"로 바로 한 번.

## 고양이 알림 문구·설정 표
`phrases.json`(데이터 폴더): 에이전트 알림 문구(`done.claude`·`done.codex`·`done.many`·`context.high`·`context.half`, `{agent}`·`{name}`·`{count}`·`{pct}` 자리표시)와 설정(`done.window_s`·`gate.normal_min`·`gate.urgent_min`·`context.half_pct`·`context.high_pct`·`context.top_pct`). 앱이 켤 때 빠진 키를 기본값으로 채운다. 자리표시가 빠진 문구나 범위 밖 값은 받지 않는다.

## 고양이 알림 줄이기
- 에이전트 "답 끝남"은 15초(`done.window_s`) 동안 모았다가 한 마디로 말한다 ("✅ 3개 끝났다냥. 하나씩 봐라냥" + 이름들).
- 컨텍스트 경고는 대화마다 50%(조용히) · 80% · 90%에서 한 번씩만 (`context.*_pct`). 알린 단계는 UserDefaults(`agentContextWarned`, 7일)에 남겨 다시 켜도 반복하지 않고, 정리(compact)로 40% 아래로 내려가면 처음부터 다시 센다.
- 한도·맥 상태·에이전트 알림은 첫 줄에서 숫자만 다른 같은 말이면 30분(급하면 10분) 안에 다시 말하지 않는다 (`NoticeBatch.Gate`). 고양이 대화 답은 거르지 않는다.
- 말투는 모두 "~다냥" (pet/docs/CAT_VOICE.md).

## 데이터
- `~/Library/Application Support/Meowgent/actlog.db` (SQLite, 본인만 읽기 가능). 옛 경로 `…/ActLog`는 같은 곳을 가리키는 심볼릭 링크(brain·tools가 그대로 읽는다)
- 지우는 기능은 아직 없음 (오래 보관). 크기는 `--stats`로 확인.
- 고양이 말풍선 반응: `reactions.jsonl`(말풍선마다 보임·답함·무시·👎·🔇, 최근 2만 줄)과 `muted.json`(🔇로 내일 아침까지 끈 종류). 고양이만 상태에서도 남고 밖으로 보내지 않는다. 말풍선을 우클릭하면 👎·🔇를 고를 수 있다.
- 앱 정리용으로 앱별 마지막 사용 시각(앱마다 최신값 하나, 30일 보관)을 활동 기록이 켜져 있을 때만 UserDefaults에 둔다. 기록을 끄면 지운다.
- 말하는 고양이(`brain/cat_mind.py`, 선택)를 켜면 고양이를 부를 때마다 활동 요약(앱·창 제목·판단, 입력한 글은 빼고)과 사용자가 건 말이 사용자의 Codex 계정으로 간다. 범위와 끄는 법은 [docs/CAT_MIND.md](../docs/CAT_MIND.md).
- 그 밖에 외부로 보내는 것은 날씨 조회 하나뿐: 고양이 햇살을 맑은 날에만 띄우려고 30분마다 [Open-Meteo](https://open-meteo.com)에 좌표(소수 한 자리, 약 10km 단위)만 보낸다. 기록·입력 내용은 보내지 않는다.
- Grok Bot 전달(직접 켰을 때만): 데이터 폴더에 `grokbot-webhook.json`을 넣으면, 다른 에이전트가 inbox에 `"forward": "grokbot"`을 붙여 넣은 할일 글만 그 루틴 웹훅으로 보낸다. 키·카드번호 같은 것은 가리고 보낸다 ([docs/INBOX.md](../docs/INBOX.md#grok-bot으로-넘기기)).
  위치 바꾸기: `defaults write com.jason.actlog petLat -float 37.5; defaults write com.jason.actlog petLon -float 127.0` · 끄기: `defaults write com.jason.actlog petWeather -bool false` (그땐 해 뜨고 지는 시간만 본다)
